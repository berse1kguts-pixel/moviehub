# 🎬 观影中心（个人版）

本地影视聚合播放器 + 音乐播放器 + Spotify 接入。**一个窗口搜全网片库和曲库，自动换源播放。**

现在有两种运行方式：
- **网页版**：双击 `启动.bat`，浏览器访问（电视/手机同局域网也能看）
- **桌面版**：双击 `桌面版启动.bat`，Electron 独立窗口，功能与网页版一致

## 快速开始

1. 安装 [Node.js](https://nodejs.org/)（要求 v16+）
2. 双击 **`启动.bat`**（网页版）或 **`桌面版启动.bat`**（桌面版）
3. 开始搜片 / 搜歌

> 电视 / 手机观看（网页版）：与电脑同一局域网，访问 `http://<电脑局域网IP>:7000`
> 查看 IP：`ipconfig` 看「IPv4 地址」（家里通常是 192.168.x.x）

## 界面说明

- **影视**：继续观看 / 最近搜索 / 最新入库；详情页有海报 + 简介 + 播放线路标签 + 选集；`Esc` 快速返回
- **分类**：左侧分类树（按源自动发现）→ 右侧海报网格，支持年份筛选、排序切换、328 页分页；点卡片直接进详情开播
- **音乐**：三个标签页
  - **本地音乐**：搜索 → 点 ▶ 播放（不可播自动切下一首）；右侧歌词滚动 + 播放列表
  - **Spotify**：未配置时显示三步接入指引；登录后可搜索 Spotify 曲库、切换播放通道
  - **播放列表**：跨平台收藏（本地歌曲 + Spotify 曲目），双击播放，支持列表/单曲/随机
- 底部播放条：上一首/播放暂停/下一首、进度条、播放模式、当前音质与解析来源

## 分类浏览的实现方式

苹果CMS V10 **没有分类树接口**，`area`/`by` 等筛选参数各源支持不一（实测只有 `year` 大多数源支持）。所以采用：

1. **采样发现**：逐页拉 `ac=videolist`，从返回项里收集 `type_id` / `type_id_1`（父级）/ `type_name`，连续 2 页无新分类即停
2. **两级补全**：父级分类名用 `t=<父ID>` 的首条数据反查
3. **不卡首屏**：先快速采样（6 秒预算）立即返回，剩余采集在后台继续，`version` 递增；前端每 4 秒轮询，树变完整自动刷新（保留选中项）
4. **磁盘缓存**：补全结果存 `.cache/classes/<源>.json`，7 天有效——**重启后 0.02 秒秒开**

实测：百度资源首次 9.3 秒出 20 个分类 → 后台补全到 23 个 → 重启 0.02 秒。年份筛选实测生效（动作片 5029 部 → 2020 年 260 部）。

配置位置 `music-sources.json`（洛雪自定义源脚本，作为扩展通道）：

```json
{ "id": "sixyin", "name": "六音音源", "url": "https://raw.githubusercontent.com/pdone/lx-music-source/main/sixyin/latest.js", "enabled": true }
```

脚本按洛雪官方协议在 **vm 沙箱**中运行，只暴露 `lx.request` / `lx.utils`（buffer、crypto、zlib），不含 `require`/`process`/`fs`，无法触碰本机文件。失效后换一个 URL 即可，服务端有 12 小时缓存。

### 音频代理（`/api/mplay`）

与影视的 `/api/play` 对称：解决防盗链、跨域、UA 校验，**支持 Range 请求**（拖动进度条不断流），自动识别 mp3/flac/m4a/ogg/wav。

## Spotify 接入

Spotify 音频有 DRM，**不存在免费直连源**。可用的三条路：

| 通道 | 需要 | 音频输出 |
| --- | --- | --- |
| librespot 本地设备 | Premium + `librespot.exe` | 本机声卡 |
| 浏览器 Web Playback SDK | Premium + 登录 | 浏览器 |
| 30 秒试听 | 任意账号 | 浏览器 |

配置步骤：
1. 打开 <https://developer.spotify.com/dashboard>，用 Spotify 账号创建应用
2. Redirect URI 填 `http://127.0.0.1:7123/spotify/callback`
3. 复制 Client ID 粘贴到 `spotify.json` 的 `clientId`，重启

登录走 **Authorization Code + PKCE**（无需 client_secret），token 存在本机 `.cache/spotify-token.json`。授权页在浏览器打开，服务端内置回调服务器（7123 端口）**自动接收 code**，无需手动复制地址。

librespot 安装（可选）：`cargo install librespot` 或放到 `moviehub/bin/librespot.exe`。官方 releases **只发布源码**，没有预编译包。

## 常见问题

**Q：搜索没结果 / 一直转圈？**
资源站普遍有 WAF 频控。稍等 10-30 秒重试，或切换到单个源再搜。

**Q：播放黑屏 / 一直缓冲？**
先等 10 秒（本地代理在重写分片地址）；仍不行返回详情换一条「播放线路」——不同源用的是不同 CDN，总有一条通。

**Q：歌点下去提示"不可播，自动切换"？**
该版本（如 Live 版/纪念版）没有版权，自动切到下一首。多切几次还没声音说明这首歌整体下架了。

**Q：Spotify 显示免费账号？**
免费账号只能 30 秒试听；完整播放需要 Premium（librespot 和 Web Playback SDK 都要求 Premium）。

**Q：想改端口？**
`set PORT=8080 && node server.js`；Spotify 回调端口改 `spotify.json` 的 `redirectPort`，记得同步改 Spotify 后台的 Redirect URI。
